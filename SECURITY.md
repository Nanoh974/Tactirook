# Security policy

## Supported versions

Tactirook is pre-release. Security fixes are currently maintained on `main`;
there are no supported stable release branches or published mobile store builds.
Older commits and independently distributed forks may not receive fixes.

## Report privately

Please use GitHub's
[private vulnerability reporting](https://github.com/Solenia13/ChessTrainer/security/advisories/new).
Do not disclose exploit details, credentials or sensitive data in a public issue.

Include:

- Affected commit/version and platform.
- A clear description of impact and required conditions.
- Minimal reproduction steps or a proof of concept, without real user data.
- Any proposed mitigation.

Use only accounts and systems you control or have permission to test. Do not
access other people's data, perform denial-of-service testing or disrupt services.

If GitHub's private report form is unavailable, use the question/contact issue
form only to request a private contact channel, without vulnerability details.

## Response and disclosure

This is a volunteer-maintained project with no guaranteed response SLA and no
paid bug bounty. The maintainer will review reports as availability permits,
coordinate fixes and agree on disclosure timing where possible. Please allow
time to investigate before publishing technical details.

Never commit signing credentials, access tokens or user data. Dependency alerts
are useful signals, not proof that the application is free of vulnerabilities.
