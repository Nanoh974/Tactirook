# Changelog

Notable changes are recorded here. The project is still pre-release; the version
in Expo/package metadata does not indicate a published store release.

## Unreleased

### Added

- React Native / Expo application for web, iOS and Android development.
- Library of 443,224 Lichess puzzles with 73 searchable themes.
- Persistent training preferences and seen-puzzle tracking.
- Seven interface languages, light/dark appearance and board/piece customization.
- Signature pixel-art SVGs and selectable third-party piece sets.
- Keyboard, screen-reader, focus and reduced-motion improvements.
- Contribution/security/privacy documentation and GitHub issue/PR templates.
- CI validation and automated GitHub Pages preview deployment.

### Changed

- Application branding changed from ChessTrainer to Tactirook.
- Original code and documentation now use MPL-2.0; original artwork uses
  CC-BY-4.0, with attribution and an additional app-store permission from
  the maintainer for artwork they own.
- Earlier GPL-3.0-or-later grants remain valid for previously distributed
  copies. Third-party notices and licenses are unchanged.

### Release status

- iOS and Android store publication is in preparation, **not available yet**.
- Physical-device accessibility and release preparation remain ongoing.
